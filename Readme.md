
# Bullet Hell Game

A 2D Bullet Hell arcade game built in Java using Swing. The player navigates an arena, dodges procedural waves of incoming enemies, and shoots down hostile units while surviving as long as possible under dynamic difficulty scaling. View the locally stored high-scores in the high-scores page on start up.

-------------------------------------------------------------------------------------------

## Requirements

* **Java Development Kit (JDK):** Version 17 or higher.
* **Apache Netbeans IDE** Version 31 or higher.
* OR 
* **VS Code** with the **Extension Pack for Java**.

-------------------------------------------------------------------------------------------

## How to Build and Run
### Option 1: Netbeans
1. Open the project folder in Apache Netbeans IDE
2. Open **src/main/java/Programming/CBL/Main.java**
3. Run the file or click SHIFT + F6.

### Option 2: In VS Code 
1. Open the project folder in VS Code.
2. Open **src/main/java/Programming/CBL/Main.java**.
3. Click the **Run** button located in the top-right corner, or press "F5".
   > VS Code will automatically compile all project files and launch the application.

-------------------------------------------------------------------------------------------

## Controls

* **Movement:** "Arrow Keys"
* **Aiming:** Mouse cursor
* **Shooting:** Automatic rapid fire towards cursor
* **Pause:** "ESC"
* **Restart:** "R" / "Enter" (when eliminated) or click **Try Again**
